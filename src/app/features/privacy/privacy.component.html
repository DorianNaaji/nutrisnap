Politique de confidentialité

NutriSnap est une application privacy-first : aucun compte, aucun serveur, aucune télémétrie. Toutes vos données restent sur votre appareil. Ce document explique précisément ce qui se passe avec vos données.

1. Responsable de traitement

Dorian Naaji
Contact : privacy@dorian-naaji.fr

NutriSnap est une application personnelle, non commerciale, développée à titre de projet individuel.

2. Données traitées

Les données suivantes sont traitées uniquement sur votre appareil (IndexedDB, navigateur local) :

  • Profil métabolique : sexe, âge, poids, taille, masse grasse, masse musculaire, niveau d'activité, objectif.
  • Clé API Google Gemini : stockée localement, jamais transmise à NutriSnap.
  • Historique alimentaire : repas scannés, calories, macronutriments, photos, analyses.
  • Préférences : thème (clair/sombre/système), langue.

lock Dorian Naaji n'a aucun accès technique à ces données. Elles ne quittent jamais votre appareil vers les serveurs de NutriSnap — il n'en existe pas.

3. Transferts vers Google Gemini (tiers)

C'est le seul point de transfert de données vers un tiers. Lors de l'analyse d'un repas, les éléments suivants sont envoyés directement depuis votre navigateur à l'API Google Gemini :

  • L'image ou les images du repas (format base64)
  • Le contexte nutritionnel du jour (calories consommées, objectif calorique)
  • La description textuelle éventuelle que vous saisissez

Ce transfert est initié par vous lors du scan. NutriSnap ne conserve pas ces données — elles transitent uniquement au moment de l'analyse, via votre propre clé API.

La gestion, la sécurité et la conservation de ces flux relèvent exclusivement de Google. Consultez la politique de confidentialité de Google et les conditions d'utilisation de l'API Gemini.

4. Stockage local & cookies

NutriSnap n'utilise aucun cookie de tracking, publicité ou analyse. Le stockage repose sur IndexedDB, une API de stockage native au navigateur. Il s'agit d'un stockage first-party, nécessaire au fonctionnement de l'application.

Ce type de stockage ne relève pas de la directive ePrivacy sur les cookies — aucun consentement supplémentaire n'est requis. Vos données restent sur votre appareil indéfiniment, sous votre contrôle exclusif.

5. Vos droits (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD — UE 2016/679), vous disposez des droits suivants :

  • Droit d'accès : vos données sont disponibles directement dans l'application (profil, historique).
  • Droit de rectification : modifiez vos données à tout moment depuis votre profil.
  • Droit à l'effacement : le bouton "Effacer toutes mes données" dans votre profil supprime l'intégralité des données locales.
  • Droit à la portabilité : export JSON disponible depuis votre profil.
  • Droit d'opposition : n'utilisez pas l'application — aucune donnée n'existe si vous n'en créez pas.

Pour exercer un droit ou poser une question : privacy@dorian-naaji.fr

6. Sécurité

L'application est servie exclusivement en HTTPS. La clé API Gemini est stockée dans IndexedDB, accessible uniquement par l'application sur votre navigateur. NutriSnap ne la transmet à aucun serveur intermédiaire.

L'application est open source — son code est intégralement vérifiable pour confirmer l'absence de collecte cachée.

7. Modifications de cette politique

Cette politique peut être mise à jour. La date de dernière révision est indiquée en haut de ce document. En cas de modification substantielle affectant vos droits, une note sera ajoutée à l'onboarding lors de la prochaine ouverture.
