1. Vision Produit & Direction Artistique

AGENT INSTRUCTION:
Abandonner le vert pastel (#e8f5e9) et les bordures vertes fluo. Le nouveau standard est "Premium Health OS". L'interface doit ressembler à un outil clinique moderne, SaaS (ex: Apple Health, Oura, Linear). Utiliser des ombres douces (--elevation-1), des coins très arrondis (--radius-xl pour les cartes principales) et un fond d'écran légèrement teinté (--md-sys-color-background).
  • ADN Visuel : Crédible, scientifique, clair, premium.
  • Principes UI : Haut contraste pour les données (noir/blanc), couleurs sémantiques uniquement pour les statuts ou les visualisations (graphiques).
  • Surfaces : Utilisation du Material 3 (Surface, Surface Container, Surface Variant) pour créer de la profondeur sans abuser des bordures.

3. Angular Material 3 Mapping Rules

AGENT INSTRUCTION - THEME CONFIGURATION:
Générer un thème personnalisé Angular Material utilisant M3.

Règles de mapping des composants :
- mat-card : Ne jamais utiliser "mat-elevation-z*". Utiliser les tokens CSS personnalisés (box-shadow: var(--elevation-1)) et border-radius: var(--radius-xl).
- mat-form-field : Utiliser appearance="outline" systématiquement.
- mat-button :
  * Action principale (Enregistrer) : mat-flat-button color="primary"
  * Action secondaire : mat-stroked-button
  * Navigation tab (Retour) : mat-button
- mat-progress-bar : Utiliser color="primary" pour les calories globales, personnaliser via CSS pour les macros spécifiques.

6. Dark Mode & Implémentation

AGENT INSTRUCTION - THEME SWITCHING:
Angular Material 3 gère le dark mode via les classes ou attributs HTML (ex: <html data-theme="dark">). Il faut lier le toggle utilisateur à cet attribut. Ne pas forcer les couleurs en dur (`#fff` ou `#000`) dans le SCSS des composants. Utiliser strictement les tokens définis dans la section 2. Les contrastes doivent respecter AA minimum.
